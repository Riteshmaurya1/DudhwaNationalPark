## Quick Reference

### 🛠 Local Development Setup
1. **Clone repo**: `git clone https://github.com/Riteshmaurya1/DudhwaNationalPark.git`
2. **Install dependencies**: `npm install`
3. **Run dev server**: `npm run dev`
4. **Lint code**: `npm run lint`
5. **Build production**: `npm run build`

### 🌿 Branch Naming Conventions
- `feat/feature-name` (New features)
- `fix/bug-name` (Bug fixes)
- `docs/doc-update` (Documentation updates)
- `refactor/component-name` (Code restructuring)
- `perf/optimization` (Performance enhancements)

### 💬 Commit Message Format
- `feat(scope): add new feature`
- `fix(scope): resolve bug`
- `docs(scope): update documentation`

For full details on architecture, design tokens, Three.js 3D fallbacks, and ecological research standards, please see [**CONTRIBUTING.md**](CONTRIBUTING.md).
