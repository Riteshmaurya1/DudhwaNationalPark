# SEO STRATEGY & METADATA ARCHITECTURE
## Organic Search Optimization for Dudhwa National Park

### 1. High-Intent Target Keyword Matrix

| Primary Topic | Target Keywords | Search Intent | Target Route |
| :--- | :--- | :--- | :--- |
| **Park Overview** | Dudhwa National Park, Dudhwa Tiger Reserve, Terai Eco System | Informational / Educational | `/` & `/explore` |

### 2. Structured Data Schema (JSON-LD)
Every route includes semantic JSON-LD schema generation:
- `Park / NationalPark` schema for main park entity.
- `TouristAttraction` schema for safari zones and rest houses.
- `Article` schema for stories and conservation journals.
- `BreadcrumbList` schema for seamless hierarchical breadcrumbs.
