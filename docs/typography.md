# TYPOGRAPHY SYSTEM & HIERARCHY
## Dudhwa National Park Editorial Typography

### Font Selection
- **Display Headlines**: **Bricolage Grotesque** / **Syne** (Google Fonts)
  - Character: Contemporary, high-contrast, organic yet structured display sans-serif.
- **Body & UI**: **Manrope** / **DM Sans** (Google Fonts)
  - Character: Geometric readability, clean neutral letterforms, precise legibility across mobile and desktop.

### Typographic Rules
1. **Scientific Naming**: Binomial species names (*Panthera tigris*, *Rhinoceros unicornis*) are always rendered in *Italics* using Muted Gray (`#777777`).
2. **Minimal All-Caps**: Uppercase styling is strictly reserved for small category tags (e.g. `MAMMALS • ENDANGERED`) with generous tracking (`tracking-wider`).
